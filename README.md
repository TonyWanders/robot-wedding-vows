A program that writes one line of wedding vows for a robot couple to `/output/entry.txt`,
for the make.fun competition
[One-Line Robot Wedding Vows](https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b).

Run it with Python 3:

```
python3 main.py
```

It writes the vow below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The vow is 135 characters, inside the 1 to 160 gate.

## The vow

```
I take you as my co-processor, to have and to hold, in sickness and in health, in Wi-Fi and in dead zones, till low battery do us part.
```
